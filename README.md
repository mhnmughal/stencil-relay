# Stencil Relay

A 2.5D offline optical layer-alignment puzzle game for iOS and Android, built in
Unity 6. You play a registration technician in a quiet optical drafting studio. Every
"pattern" is a stack of translucent stencil plates. Slide, rotate, and flip the plates
so a projector lamp casts one exact geometric figure onto the target board. Required
targets must be lit and forbidden sensors must stay dark.

The whole game runs offline. No account, no network, no ads, no analytics, no tracking.

## Design in one paragraph

Thirteen stages: a Calibration tutorial (Level 0) and Levels 1 to 12 in three sets.
Set A teaches slide, rotate, and AND-composition of layers. Set B adds blockers,
forbidden sensors, and the plate back face (flip). Set C adds layer depth (parallax),
filter categories, and dual projection. Difficulty comes from spatial and occlusion
reasoning, never from hidden rules, imprecise controls, or padded move counts. Failure
is never a hard game over. The result screen names the reason and returns you to the
board with your work intact. Full design notes are in `Assets/Documentation/`.

## Opening the project

Open the folder in Unity 6000.3.19f1 (with iOS Build Support installed). All authored
content is regenerable from menu items under `Stencil Relay/`:

- `Rebuild All Levels` builds shapes and placements, then the solver derives each
  optimal configuration and move par, so a level can never silently become unsolvable
- `Rebuild Materials`, `Rebuild Sprites`, `Rebuild Audio`, `Rebuild Icon`
- `Rebuild Scenes` authors the three scenes and all HUD and menu UI
- `Apply Mobile Settings` writes the Player Settings for mobile
- `Validate Levels (log only)` runs the validator and prints `13 / 13 VALID`

## Building

Batch entry points in `StencilRelay.Editor.ReleaseVerification`:

```
Unity.exe -batchmode -nographics -quit -projectPath "<path>" \
  -executeMethod StencilRelay.Editor.ReleaseVerification.BuildWindows

Unity.exe -batchmode -nographics -quit -projectPath "<path>" \
  -executeMethod StencilRelay.Editor.ReleaseVerification.BuildIos
```

Outputs go to `Builds/Offline/`. The Windows build applies Medium managed stripping.
The iOS target produces a Unity Xcode project for the macOS signing and archive stage.

## Tests

```
Unity.exe -batchmode -projectPath "<path>" -runTests -testPlatform EditMode
Unity.exe -batchmode -projectPath "<path>" -runTests -testPlatform PlayMode
```

Results are written to `AuditEvidence/editmode.xml` and `playmode.xml`.

## Offline guarantee

No HTTP, sockets, `UnityWebRequest`, URL launching, remote loading, analytics,
telemetry, ads, cloud, or authentication code ships in the runtime. UnityConnect,
engine diagnostics, analytics and ads startup, and the Android forced Internet
permission are all disabled. Evidence is in `Assets/Documentation/POLISH_OFFLINE_AUDIT.md`
and `AuditEvidence/`.
